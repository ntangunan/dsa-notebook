===========================================
OPERATIONS OF DYNAMIC ARRAY:
===========================================

1. Access
---------
Retrieve an element by its index.

Example:
arr = [10, 20, 30]
print(arr[1])          # 20

Time: O(1)

-------------------------------------------

2. Update
---------
Modify an element at a specific index.

Example:
arr = [10, 20, 30]
arr[1] = 50

Result:
[10, 50, 30]

Time: O(1)

-------------------------------------------

3. Search
---------
Find an element in the array.

Example:
arr = [10, 20, 30]

20 in arr             # True
arr.index(30)         # 2

Time: O(n)

-------------------------------------------

4. Append
---------
Add an element to the end of the array.

Example:
arr = [10, 20]
arr.append(30)

Result:
[10, 20, 30]

Time: O(1) amortized

-------------------------------------------

5. Insert
---------
Insert an element at a specific index.

Example:
arr = [10, 20, 40]
arr.insert(2, 30)

Result:
[10, 20, 30, 40]

Time: O(n)

-------------------------------------------

6. Delete
---------
Remove an element.

By Index:
arr.pop(1)

By Value:
arr.remove(20)

Result:
[10, 30, 40]

Time: O(n)

-------------------------------------------

7. Pop (End)
------------
Remove and return the last element.

Example:
arr = [10, 20, 30]

value = arr.pop()

Result:
value = 30
arr = [10, 20]

Time: O(1)

-------------------------------------------

8. Length
---------
Get the number of elements.

Example:
arr = [10, 20, 30]

len(arr)

Result:
3

Time: O(1)
