===========================================
COMPLEXITIES OF DYNAMIC ARRAY
===========================================

+----------------------+----------------------+----------------------+----------------------+
| Operation            | Time                 | Space                | Python Code          |
+----------------------+----------------------+----------------------+----------------------+
| Access               | O(1)                 | O(1)                 | arr[i]               |
| Update               | O(1)                 | O(1)                 | arr[i] = x           |
| Search               | O(n)                 | O(1)                 | x in arr             |
| Append               | O(1) amortized*      | O(1)                 | arr.append(x)        |
| Pop (End)            | O(1)                 | O(1)                 | arr.pop()            |
| Insert (Middle)      | O(n)                 | O(1)                 | arr.insert(i, x)     |
| Delete (Middle)      | O(n)                 | O(1)                 | arr.pop(i)           |
| Length               | O(1)                 | O(1)                 | len(arr)             |
+----------------------+----------------------+----------------------+----------------------+
