===========================================
DYNAMIC ARRAY INTERVIEW QUESTIONS
===========================================

Dynamic array questions usually test:
- Index manipulation
- Traversal
- Two pointers
- Sliding window
- In-place modification
- Sorting
- Searching
- Understanding array operations

===========================================
BEGINNER QUESTIONS
===========================================

1. Find Maximum Element
-----------------------
Problem:
Given an array, find the largest number.

Example:
Input:
[3, 7, 2, 9, 1]

Output:
9

Concepts:
- Traversal
- Comparison

Time: O(n)
Space: O(1)


-------------------------------------------

2. Reverse an Array
-------------------
Problem:
Reverse an array without using extra space.

Example:

Input:
[1,2,3,4,5]

Output:
[5,4,3,2,1]

Concepts:
- Two pointers
- In-place modification

Time: O(n)
Space: O(1)


-------------------------------------------

3. Remove Duplicates from Sorted Array
--------------------------------------
Problem:
Remove duplicates in-place and return new length.

Example:

Input:
[1,1,2,2,3]

Output:
[1,2,3]

Concepts:
- Two pointers
- In-place modification

Time: O(n)
Space: O(1)


-------------------------------------------

4. Move Zeroes
--------------
Problem:
Move all zeros to the end while maintaining order.

Example:

Input:
[0,1,0,3,12]

Output:
[1,3,12,0,0]

Concepts:
- Two pointers

Time: O(n)
Space: O(1)


===========================================
INTERMEDIATE QUESTIONS
===========================================

5. Two Sum
-----------
Problem:
Find two numbers that add to a target.

Example:

Input:
nums = [2,7,11,15]
target = 9

Output:
[0,1]

Concepts:
- Array traversal
- Hash map

Time: O(n)
Space: O(n)


-------------------------------------------

6. Maximum Subarray (Kadane's Algorithm)
-----------------------------------------
Problem:
Find the contiguous subarray with the largest sum.

Example:

Input:
[-2,1,-3,4,-1,2,1]

Output:
6

Subarray:
[4,-1,2,1]

Concepts:
- Dynamic programming
- Sliding window idea

Time: O(n)
Space: O(1)


-------------------------------------------

7. Best Time to Buy and Sell Stock
----------------------------------
Problem:
Find the maximum profit from buying and selling once.

Example:

Input:
[7,1,5,3,6,4]

Output:
5

Buy: 1
Sell: 6

Concepts:
- Traversal
- Tracking minimum

Time: O(n)
Space: O(1)


-------------------------------------------

8. Rotate Array
---------------
Problem:
Rotate an array to the right by k positions.

Example:

Input:
[1,2,3,4,5,6,7]
k = 3

Output:
[5,6,7,1,2,3,4]

Concepts:
- Array manipulation
- Reversal technique

Time: O(n)
Space: O(1)


-------------------------------------------

9. Product of Array Except Self
-------------------------------
Problem:
Return an array where each element is the product of all other elements.

Example:

Input:
[1,2,3,4]

Output:
[24,12,8,6]

Concepts:
- Prefix sum
- Suffix products

Time: O(n)
Space: O(1) extra


===========================================
ADVANCED QUESTIONS
===========================================

10. Merge Intervals
-------------------
Problem:
Merge overlapping intervals.

Example:

Input:
[[1,3],[2,6],[8,10]]

Output:
[[1,6],[8,10]]

Concepts:
- Sorting
- Array processing

Time: O(n log n)


-------------------------------------------

11. 3Sum
--------
Problem:
Find all unique triplets that sum to zero.

Example:

Input:
[-1,0,1,2,-1,-4]

Output:
[[-1,-1,2],[-1,0,1]]

Concepts:
- Sorting
- Two pointers

Time: O(n²)


-------------------------------------------

12. Trapping Rain Water
----------------------
Problem:
Calculate water trapped between bars.

Example:

Input:
[0,1,0,2,1,0,1,3]

Output:
6

Concepts:
- Two pointers
- Prefix/suffix maximum

Time: O(n)
Space: O(1)


-------------------------------------------

13. Longest Substring Without Repeating Characters
--------------------------------------------------
Problem:
Find the longest substring without duplicate characters.

Example:

Input:
"abcabcbb"

Output:
3

Substring:
"abc"

Concepts:
- Sliding window
- Hash map

Time: O(n)


-------------------------------------------

14. Median of Two Sorted Arrays
-------------------------------
Problem:
Find the median of two sorted arrays.

Example:

Input:
[1,3]
[2]

Output:
2

Concepts:
- Binary search
- Array partitioning

Time: O(log(n+m))


===========================================
IMPLEMENTATION QUESTIONS
===========================================

15. Implement a Dynamic Array
-----------------------------
Problem:
Create your own version of Python's list.

Must support:

- append()
- get(index)
- insert(index, value)
- delete(index)
- resize()

Concepts:
- Capacity
- Size
- Memory allocation

Operations:

Access:
O(1)

Append:
O(1) amortized

Insert:
O(n)

Delete:
O(n)


-------------------------------------------

16. Design a Circular Array
---------------------------
Problem:
Implement a queue using a fixed-size array.

Concepts:
- Modulo arithmetic
- Array indexing


-------------------------------------------

17. Implement Stack Using Array
-------------------------------
Problem:
Create a stack using a dynamic array.

Operations:

push()
pop()
peek()

Concepts:
- Append/remove end

Time:
O(1)
